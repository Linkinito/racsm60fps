# Legacy V1 inventory — Overcompensated / UCES00420

## Scope, method, and evidence convention

This is a read-only inventory of the legacy project, primarily `01-Travail-et-profil-PPSSPP/Overcompensated-Reprise-2026-09-14/` (abbreviated **L/** below). It was prepared on `v2-research` against the immutable historical reference tag `legacy-60fps-pre-v2` (`9d477f056b8c3353c7d108fd3ea8a5bc4e2ed2bd`). No PPSSPP session, gameplay test, binary modification, patch build, or migration was performed for this report. The repository working tree was clean before this report was created.

The inventory examines documentation, filenames, manifests, CSV/JSON headers and summaries, selected code and script entry points, archived ZIP contents, and a sample of trace results. It is **not** a complete independent audit of every binary word, every trace event, or every historical claim. In the tables, `OBSERVED` means the stated content or file relationship is directly present in the inspected material. It does not turn a recorded gameplay assertion into a newly verified observation. `TESTED (historical)` identifies a test with a recorded environment and result in V1; its scope is stated. `INFERRED` and `CORROBORATED` are interpretations, `UNKNOWN` is unresolved, `REJECTED` identifies a contradicted hypothesis, and `SUPERSEDED` identifies a historical description replaced by better evidence. These terms follow `docs/methodology/EVIDENCE_LEVELS.md`. Migration states from `MIGRATION.md` are separate from evidence status and are **not changed here**.

Paths below use the exact `L/` prefix defined above. A path of the form `archive.zip::inner/path` identifies an entry in an unmodified ZIP. Addresses prefixed `RVA` are offsets within a loaded module; historical absolute addresses belong to particular sessions or reference bases and must not be reused as live addresses without fresh identification and word checks. Strings such as `WF-044`, object class names, and semantic labels are legacy identifiers, not new authoritative function names.

For long extracted package paths, **P45/** means `L/sources-v0.4.5/Size_Matters_wrapper_profiler_v0.4.5-prealpha_UCES00420/`, and **P50/** means `L/sources-v0.5.0/Size_Matters_wrapper_dispatcher_v0.5.0-prealpha_UCES00420/`. Both aliases identify exact directories under L/.
